# Worker Attendance Management System

A web-based Factory Worker Attendance Management System developed using **PHP, MySQL, HTML, CSS, and JavaScript**. This application is designed to simplify daily workforce management by providing an organized platform for managing employee records, tracking attendance, calculating salaries, and monitoring factory workforce activities.

## 🚀 Features

- **Dashboard:** Get an overview of factory workforce activities.
- **Employee Management:** Add, view, update, and manage worker information.
- **Attendance Management:** Maintain and track daily worker attendance.
- **Salary Management:** Calculate and manage worker salaries.
- **Attendance Reports:** View and export attendance records.
- **Worker Records:** Maintain centralized employee information.
- **User Authentication:** Secure login and registration functionality.
- **Responsive Interface:** Simple and user-friendly interface.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** XAMPP / Localhost

## 💻 Installation & Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/dev-shivam-21/Worker-attendance-system-.git
   ```

2. Move the project folder into your XAMPP `htdocs` directory.

3. Start Apache and MySQL from the XAMPP Control Panel.

4. Create a MySQL database using phpMyAdmin.

5. Configure your database connection details in `config.php`.

6. Ensure the required database tables are created.

7. Open your browser and visit:

   ```text
   http://localhost/Worker-attendance-system-
   ```

## 🎯 Project Objective

The main objective of this project is to digitize and simplify factory workforce management. It helps reduce manual paperwork, improve attendance tracking, organize employee records, and make salary management more efficient.
